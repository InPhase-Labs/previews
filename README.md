# InPhase Labs previews

Clickable prototypes built by [InPhase Labs](https://inphaselabs.com). Each preview is a self-contained page in its own folder and runs with sample data only.

| Preview | Folder | What it shows |
|---|---|---|
| Throughline | `throughline/` | Coaching results platform: interview intake, synthesis, and tailored views for the coach, exec sponsor and interviewees |

## Adding a preview

1. Create a folder named after the preview, for example `activity-mapper/`.
2. Put the page in it as `index.html`.
3. Add a row to the table above and a card to the top-level `index.html`.

All names and data in these previews are fictional.
